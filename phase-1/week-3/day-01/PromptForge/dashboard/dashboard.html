Your key, your call.
API credentials are stored in Chrome extension storage. Session-only mode clears the key when the browser session ends. Chrome storage is not a dedicated secrets vault.
  • Requests happen only after you generate, refine, or test.
  • Credentials are not inserted into prompt text or exports.
  • Prompt history remains local to this browser profile.

            
Provider notes
OpenAI-compatible: uses Chat Completions and expects a JSON response.
Groq: uses the OpenAI-compatible Chat Completions API at api.groq.com.
Anthropic: uses Messages API with browser access enabled by its request header.
Gemini: uses generateContent and the x-goog-api-key authentication header.
Only use API keys and endpoints you trust. Review the provider's data-retention terms.
